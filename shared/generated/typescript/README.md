# `@ym-connect/protocol`

This package is the canonical JavaScript and TypeScript binding for the YM Connect v1
Protocol Buffer schema. It is generated by `protoc-gen-ym-connect` and deliberately has no
runtime dependencies, which keeps the browser extension supply chain and bundle surface small.

The package exports message schemas, enum objects, structural TypeScript interfaces, binary
codecs, canonical JSON conversion, deep cloning, equality checks, and a type registry.

```js
import {
  ProtocolVersionSchema,
  create,
  fromBinary,
  toBinary,
} from "@ym-connect/protocol";

const version = create(ProtocolVersionSchema, { major: 1, minor: 0, patch: 0 });
const bytes = toBinary(ProtocolVersionSchema, version);
const decoded = fromBinary(ProtocolVersionSchema, bytes);
```

Decoding defaults to a 1 MiB input limit and a maximum nesting depth of 64. Callers may lower
those limits at trust boundaries.
