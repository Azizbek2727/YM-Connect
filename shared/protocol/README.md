# YM Connect protocol v1

The v1 schema covers four boundaries:

1. Browser Connector to native host through `ConnectorEnvelope`.
2. Native host to Bridge through the same canonical connector payloads over authenticated
   platform IPC.
3. Android client to Bridge through `EncryptedFrame`, which contains an authenticated encrypted
   `ClientEnvelope` after handshake completion.
4. Pairing and discovery through signed advertisement and pairing messages.

All integer timestamps are Unix epoch milliseconds. Durations and positions are milliseconds.
Identifiers are opaque ASCII strings generated by the owning endpoint. Public keys, signatures,
nonces, ciphertext, digests, and fingerprints are raw bytes rather than textual encodings.

The maximum serialized envelope size is 1 MiB. Native-messaging and platform-IPC transports use
a four-byte unsigned big-endian length prefix around serialized envelopes. The encrypted LAN
transport authenticates frame metadata as associated data and enforces monotonically increasing
64-bit sequence numbers per direction.

## Reproducible generation

The canonical descriptor set and Java Lite sources are generated with Protocol Buffer compiler
3.13.0. `shared/protocol/buf.gen.yaml` passes the `lite` generator option explicitly. Repository
generation requires that compiler to be available as `protoc`; the repository-owned generator
produces the TypeScript, Rust, and Kotlin surfaces from the same input files.
